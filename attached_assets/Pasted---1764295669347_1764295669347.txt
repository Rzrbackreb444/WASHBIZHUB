────────────────────────────── UNIVERSAL FIRST 3 STEPS (DO THESE EVERY TIME) ──────────────────────────────
1. Unplug 60 seconds → plug back in (clears 40% of all codes)
2. Check 220–240V at the wall with a meter (voltage drops = 25% of “no heat” calls)
3. Clean lint filter + exhaust duct (clears 60% of airflow codes)

Now the full repair list — organized by symptom/code (works for EVERY brand unless noted).

──────────────────────────────────────────────────────────────────────────────────────
NO FILL / SLOW FILL / E10 / IE / F20 / E-FL / Alm-A / W002
──────────────────────────────────────────────────────────────────────────────────────
1. Check water turned on + hoses not kinked
2. Pull inlet screens → clean with toothbrush (85% fix)
3. Swap hot/cold hoses (HO_SE on Electrolux)
4. Test inlet valves with meter (0 Ω = bad)
5. Replace valve(s) — 10-minute job
Part: Inlet valve (see brand list above) — $45–$65

──────────────────────────────────────────────────────────────────────────────────────
NO DRAIN / SLOW DRAIN / OE / E20 / E21 / F21 / dE / ndr / AL02
──────────────────────────────────────────────────────────────────────────────────────
1. Remove & clean coin trap / pump filter (70% fix)
2. Check drain hose not kinked or >8 ft high
3. Run test cycle with no clothes → listen for pump hum
4. If humming but no drain → replace pump (15 min)
5. If silent → check wiring or triac on board
Part: Drain pump — $65–$95

──────────────────────────────────────────────────────────────────────────────────────
NO SPIN / NO TUMBLE / ROTATION FAULT / E:RT / DF08
──────────────────────────────────────────────────────────────────────────────────────
1. Check belt (top-load & older dryers)
2. Front-load: Remove back panel → check belt or coupling
3. Speed Queen/Dexter: Check shocks/springs
4. Replace belt ($25) or shocks ($120 set) — 20–40 min
Part: Belt F808215P / 341241 / ADC-010P — $20–$28

──────────────────────────────────────────────────────────────────────────────────────
NO HEAT (GAS DRYERS) — ALL BRANDS 1990–2025
──────────────────────────────────────────────────────────────────────────────────────
1. Clean lint + check vent (60% fix)
2. Check igniter glows → if yes but no flame = bad coils
3. Check igniter glows red but weak = replace igniter
4. No glow = check thermal fuse & hi-limits
Order of replacement (90% success rate):
   1. Coils 279834 $25
   2. Igniter (see brand) $45–$55
   3. Flame sensor $22–$25
   4. Thermal fuse / hi-limit $10–$25

──────────────────────────────────────────────────────────────────────────────────────
NO HEAT (ELECTRIC DRYERS)
──────────────────────────────────────────────────────────────────────────────────────
1. Test element continuity (0 Ω = bad)
2. Check thermal fuse & hi-limits
3. Replace element + fuse kit — 30 min
Part: Element (see brand list) — $65–$90

──────────────────────────────────────────────────────────────────────────────────────
DOOR / LID / dE / E40 / E:dL / D015 / dor / F5E2
──────────────────────────────────────────────────────────────────────────────────────
1. Clean strike & latch
2. Bypass lid switch (top-load test only!)
3. Replace lock assembly — 10–20 min
Part: Door/lid lock — $55–$90

──────────────────────────────────────────────────────────────────────────────────────
UNBALANCE / UE / Er_Ub / E:ub / AL07 / F3
──────────────────────────────────────────────────────────────────────────────────────
1. Redistribute load
2. Check shocks/springs (replace all 4 if one bad)
3. Top-load: Check suspension rods
Part: Shocks (4) $90–$140 set

──────────────────────────────────────────────────────────────────────────────────────
PAYMENT / CARD READER / COIN ISSUES
──────────────────────────────────────────────────────────────────────────────────────
Greenwald/Nayax/PayRange OFFLINE → Reboot + check antenna ($25–$30)
Card not reading → Clean swipe head or replace reader ($60–$120)
Coin jam → Clear gate + clean sensors
Hamilton/Rowe EXTRA_COIN → Replace brake assembly $35

──────────────────────────────────────────────────────────────────────────────────────
TOP 10 MOST COMMON CALLS & 2-MINUTE FIXES (90% of all service calls)
──────────────────────────────────────────────────────────────────────────────────────

2. No heat gas → Replace coils $25 (15 min)

8. Card reader dead → Reboot + antenna $30
9. No tumble → Replace belt $25
