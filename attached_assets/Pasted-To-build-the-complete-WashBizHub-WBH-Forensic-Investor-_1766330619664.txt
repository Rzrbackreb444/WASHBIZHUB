1. Core Infrastructure Setup
You will need to configure three environments to communicate with each other:

Google Cloud Project: Enable the Google Classroom API and Drive API. Create OAuth 2.0 Credentials and download the credentials.json for your Replit project.

Stripe Dashboard: Set up a Webhook pointing to your Replit URL.

Replit Environment: Use the Integrated Stripe Connector for secure payment handling and Replit Secrets to store your API keys.

2. Automated Fulfillment Script (Stripe to Classroom)
This script (to be used in your main.py on Replit) listens for a successful purchase and instantly invites the student to the course and the vault.

Python

import stripe
from googleapiclient.discovery import build

# Triggered by Stripe Webhook 'checkout.session.completed'
def fulfill_wbh_order(session):
    email = session['customer_details']['email']
    
    # 1. Invite to WBH Academy on Google Classroom
    classroom = build('classroom', 'v1', credentials=creds)
    classroom.invitations().create(body={
        "userId": email, 
        "courseId": "WBH_FORENSIC_ID", 
        "role": "STUDENT"
    }).execute()
    
    # 2. Grant access to the Laundromat Larry Vault folder on Drive
    drive = build('drive', 'v3', credentials=creds)
    drive.permissions().create(fileId="VAULT_FOLDER_ID", body={
        "type": "user", "role": "reader", "emailAddress": email
    }).execute()
